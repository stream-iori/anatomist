# anatomist

Use Anatomist for indexed Java source and relationship evidence. Work from the
project checkout under analysis; select a captured version for historical questions.
For branch differences, caller impact and version navigation, read
`anatomist skill versions`.

Read `anatomist skill core` once for query and evidence rules, then execute the
query that answers the question. If the task route is unclear, read
`anatomist skill topics` and only the relevant scene.

Use command `--help` for unfamiliar arguments, `operations <command>` for typed
input/output or capability questions, and `skill maintenance` for index problems.
