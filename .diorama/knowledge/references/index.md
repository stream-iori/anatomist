# Shared Reference

Agent 在 design/plan 阶段按需阅读，或人类指定时阅读。

## 如何使用

- Agent 不主动扫描，只在人指定或 design/plan 需要时按条目读取
- 人维护此文件，添加/删除条目
- 条目可以是项目内文件路径，也可以是外部 URL
